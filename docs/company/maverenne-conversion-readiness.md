# Maverenne 转化与政策一致性审计

**审计日期：** 2026-07-26  
**范围：** 首页、集合、12 款铺货验证商品页、购物车、结账前入口、FAQ、配送/退款/条款/隐私/联系页、邮件订阅。  
**方法与边界：** 仅审阅仓库中的客户界面、代码及内部资料；未登录支付、物流、邮箱、供应商或生产账户，未创建订单或外部请求。`docs/company/maverenne-entity-fact-registry.md` 已明确：代码常量、种子数据、模型/AI 图、策略和指标目标不能证明经营事实。因此本文将界面/代码称为“技术存在证据”，不会将其当作真实履约、库存、材质、价格、评价或授权的证明。

## 结论

当前漏斗的页面与 PayPal 前端入口在技术上存在，但不具备可安全承接真实订单的政策与事实一致性。P0 是：配送、退换、支持邮箱及品牌主体均以确定语气对外承诺，却缺少对应的外部经营证据；同时 Maverenne 重定位尚未完成，客户会在购买关键环节持续看到 MythRealms。12 款验证商品的“可购买”只证明路由、加购与展示数据存在，不能证明可发货。

## 重点风险清单（按优先级）

### P0：真实接单前必须闭环

1. **配送与时效不具备外部证据。** 免费配送、$4.99、2–5 天处理、7–20 天标准、DHL 6–8 天、36 国/全球、追踪及丢件处理均只能追溯到页面或常量；没有承运、报价或妥投证据。
2. **30 天退换与退款责任未被运营事实支撑。** 没有退货地址、RMA、供应商责任或经验证的 PayPal 退款闭环；退款页、FAQ、条款应以同一经批准政策为准。
3. **12 款验证商品“可买”不等于可履约。** `isActive/inStock/价格/评分/评论` 是目录展示字段；四份 SKU 事实包明确反证其可直接证明库存或材质。Turquoise Leaf 应继续冻结；其余验证 SKU 也尚缺一款一证。
4. **品牌、合同主体、域名和支持邮箱冲突。** Maverenne 设计已获批，但客户关键页、metadata、邮件和支持地址仍大量为 MythRealms；条款称 `mythrealms.com`，技术默认域名为 `mythrealms-shop.vercel.app`。
5. **支付后能力未完成只读确认。** 既有生产验收明确记录 Resend 发件人与 PayPal webhook 未验证；这阻断订单确认、退款状态和客服承诺的可信闭环。

### P1：会降低转化或产生争议，应在流量放大前处理

1. **取消时限矛盾：** FAQ 4 小时，Terms 2 小时。
2. **优惠码缺乏活动证据：** FAQ 直接推荐 `MYTH15`；种子/验证 API 的存在不是对外活动批准。
3. **材质/低敏/库存表述缺证：** 商品文案含 freshwater/saltwater pearl、珍珠/金属等描述，且 `inStock`、Low Stock、评分/评论可见；没有低敏/防过敏证明，严禁推导或宣称。材料可见外观、供应商图或种子字段均不等于成分、镀层或致敏性证据。
4. **邮件订阅的可交付性与隐私路径不明。** 订阅成功状态不能证明发送、退订和同意记录。

### P2：体验与信任优化

1. 商品尺寸、重量、成对销售、颜色差异、图片授权和包装信息不完整，易导致预期偏差。
2. “24 小时回复”“礼品包装/无价格标签”“伙伴物流”等服务信号缺运营记录。
3. 站内仍保留 Guardian/旧品牌叙事，和 Maverenne 的新定位并列，降低用户对店铺身份的判断确定性。

## 不改客户界面即可立即完成的证据准备清单

- **物流：** 每个可服务国家的承运商、服务代码、起运地、报价、时效、追踪能力、禁运与异常赔付；保存合同、后台截图或可复核报价及日期。
- **SKU（12 款逐一）：** 原始供应商链接和联系人、可发货款式/颜色/成对单位、实时库存与更新时间、采购价/MOQ、材质与镀层证明、尺寸重量、包装、图片授权、国内发货 SLA、跨境线路及退换/补发责任。
- **退换：** 退货地址、RMA SOP、可退条件、费用归属、退款时钟、供应商责任，以及经单独授权的受控支付—退款—webhook—邮件闭环记录。
- **支付与通知：** PayPal Live webhook 的 URL/事件/签名验证截图；已验证 Resend 发件域和 Maverenne 支持邮箱的收发、回复 SLA、轮值及升级记录。
- **政策与法定主体：** Maverenne 的法定主体、真实域名、注册地址、适用法、隐私控制者/处理商、税费责任；将取消时限、配送、退换整理为一份经批准的事实表并标注生效日期。
- **促销与订阅：** 免运补贴审批、地域与有效期；每个优惠码的规则、预算、负责人及启停记录；订阅同意、退订和欢迎邮件测试证据。

## 复核门槛

在以上 P0 证据齐备并由相应负责人签字/留档前，建议把站点状态定义为“可进行需求和界面测试，不可据当前承诺接收真实履约订单”。后续任何客户界面调整应只采用已登记、可追溯、带日期和适用范围的事实；不得以代码值、种子数据、设计文档或页面文案替代经营证据。
