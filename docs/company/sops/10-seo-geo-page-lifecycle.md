本 SOP 适用于现有可索引 URL 的 SEO/GEO 页面改写、验收与复盘。它不授权创建薄页、发布、部署、DNS、canonical/redirect/noindex 变更、站长平台写入、广告或商品状态改变。

## 1. 核心证据规则

- `not_available` 表示尚无可复核读取、导出或截图；绝不以 `0`、历史截图、HTTP 200、本地测试或代码存在替代。
- **草稿、本地实现、部署、收录、AI 引用、实际访问不可混同。** 每一种状态必须有独立证据与时间范围。
- 先使用既有规范 URL；发现近义意图时优先作为现有 hub/页面的段落、FAQ 或内链候选。新路由须另有书面决策与证据，不因 SERP 抽样或无数据创建。
- 不得因缺失数据擅自设置 redirect/noindex；无明确等价目标时不跳首页。任何 redirect/noindex/canonical/sitemap 操作均属于技术与生产授权范围。
- 通用珍珠教育不证明 SKU 事实。材质、尺寸、价格、库存、配送、退换、低敏、耐用、效果与品牌法律事实只可使用当前一方主记录。
- 任一记录的 `not_available` 只表示证据未取得；它不能作为 QA 通过、代码准入、技术验收或发布授权的替代。

## 2. 生命周期与阶段门

| 阶段 | 最小输入与动作 | 通过定义 | 记录状态 / 停止条件 |
| --- | --- | --- | --- |
| 1. 查询与意图证据 | 收集 GSC/Bing 的 query/page（若可读）；或记录公开 SERP 页面类型、用户问题与日期/地区假设 | 一个可描述的用户问题、意图和页面类型；来源 URL 或平台截图可重放 | 外部读数缺失即 `not_available`；SERP 样本不是搜索量/排名/流量证据 |
| 2. 既有 URL 优先 | 在 URL 决策登记册中检查现有路由、canonical 与意图；选择单一现有目标 | 明确写出“保留 / 本地 rewrite candidate / blocked”和等价目标 | 无等价目标、已暂停历史主题或需品牌切换的页面为 `blocked`；不得新建薄页 |
| 3. 来源与 copy | 形成 H1、40–60 词直接答案、正文/FAQ、来源清单、禁止主张清单 | 每个实质性事实能回溯到权威教育来源或一方主记录；编辑建议与商品事实分开 | 草稿仅为内部文本，不能表示已实现或可索引；无来源的陈述删除或标待确认 |
| 4. 事实与链接 QA | 事实审校、SKU/政策审校、图片身份/商用权、描述性 HTML 内链、FAQ 可见文本核对 | 所有链接目标、锚文本、来源/日期/byline 与适用事实已审；FAQ 与 schema 语义一致 | 商品/政策/图片/链接任一未核验即不得进入公开代码；不得以图片推断规格 |
| 5. 隔离实现 | 在隔离分支/工作树实施已批准的本地差异，保留现有 URL 与可回滚范围 | 本地测试、静态检查和差异审阅通过；变更只含获批页面/链接/metadata 范围 | **本地实现 ≠ 部署。** 失败或范围漂移时停下并回到 QA；不触及生产 canonical/redirect |
| 6. 技术验收 | 在获授权环境核验 URL、状态、canonical、robots、sitemap、结构化数据与内链 | 规范 URL 为 200 或获批单跳永久迁移、self-canonical、无意外 noindex；sitemap 不含参数/4xx/noindex URL | **技术通过 ≠ 收录。** 未获环境/权限时为 `not_available`，不宣称失败或成功 |
| 7. 发布授权 | 汇总内容、事实、技术、品牌/法务（如适用）签字与回滚计划 | 有明确书面发布/生产授权、目标环境、变更清单和回滚负责人 | **授权 ≠ 已部署。** 没有授权不得发布、部署、提交 sitemap 或改外部平台 |
| 8. Day 0 读取 | 发布/切域后记录 America/New_York 时间；以只读方式取得 GSC/Bing/GA4/robots/sitemap 初始证据 | 平台、property/site、日期范围、时区、筛选、截图时间、执行人完整 | **部署 ≠ 收录/访问。** 无读数/平台延迟均为 `not_available`；不填 0 |
| 9. Day 7 / Day 14 复盘 | 同口径复读查询、落地页、索引与 AI 引用观察；比较数据质量而非先判胜负 | 每一项标记 `已证实`、`not_available` 或 `blocked`；可比性已说明 | GSC/Bing/GA4/AI 各自报告，不能相加或互相代替；样本不足只写证据不足 |
| 10. 更新或暂停 | 根据事实、内容时效、链接、索引和测量完整性决定维护、暂停或提出下一轮候选 | 更新有新来源/事实审校；暂停有原因、日期、owner 与重开条件 | 不以短期波动、无数据或单次 AI 引用改变 redirect/noindex/页面状态 |

## 3. 阶段 1–4：内容准入清单

每个候选页面必须在进入本地实现前完成以下字段：

- 现有规范 URL、页面目的、主查询/问题、意图、证据日期与来源。
- 直接答案、H1、FAQ（如适用）、来源/访问日期/byline、禁止主张。
- 现有可用的描述性内链，以及每条链接的用户目的；不使用“点击这里”“了解更多”等空锚文本。
- 当前状态：`keep`、`rewrite_candidate` 或 `blocked`；GSC、backlink、GA4 未取得时一律 `not_available`。
- 内容、事实、商品/政策、图像和 SEO reviewer；任何 reviewer 未完成即不进入公开代码。

### 阶段 3 来源复开与判断标记

每个来源或实质主张须使用以下字段；未完成的字段写 `not_available`，不得用历史抓取、本地测试或代码存在代替。

| 字段 | 必填记录 / 口径 |
| --- | --- |
| 来源 URL | 可复开的原始来源 URL；不是搜索结果页或二手转述。 |
| 访问日 | 人工复开的日期；未复开为 `not_available`。 |
| 审阅人 | 复开并核对支持范围的 reviewer 角色/具体人员；具体人员未知时写待确认。 |
| 支持范围 | 对应页面段落、FAQ 或 schema 字段，以及来源实际支持的事实边界。 |
| 判断标记 | 仅可为 `external_fact`、`editorial_judgment` 或 `first_party_product_policy_fact`。 |
| 失效 / 复查条件 | 来源不可访问、内容变更、政策/SKU 更新、或既定复盘日到达时重新审校。 |

判断标记规则：`external_fact` 必须有上表完整来源复开记录；`editorial_judgment` 必须明确为可选、偏好或编辑建议，不能伪装为普适事实、产品事实或结果承诺；`first_party_product_policy_fact` 必须指向当前 SKU、政策或支持主记录，不能由图片、通用教育或另一 SKU 推断。任何无法分类的主张删除或标为待确认。

### 阶段 4 事实、链接、图片与 FAQ/schema QA 字段

#### 链接与图片权利记录

每条拟加入的普通 HTML 链接与每张拟使用的图像均须逐项留档：

| 对象 | 最小字段 | 通过口径 | 未通过处理 |
| --- | --- | --- | --- |
| 普通 HTML 链接 | 来源页面 URL、目标 URL、描述性锚文本、用户目的、目标 Owner/reviewer、目标环境可达性、事实边界、review_date | 目标与锚文本准确、可达并已由对应 Owner/reviewer 核验；链接不被用作 SKU、政策或产品属性的证明。 | 不加入该链接；若页面意图或事实边界依赖该链接，则页面停在阶段 4。 |
| 图片 / 编辑图 | 资产 ID/路径、来源、商业使用权/许可记录、可见内容、SKU 关联状态、事实边界、reviewer、review_date | 图片身份和权利有可复核记录；图片不被用来推断 SKU 材质、类型、尺寸、重量、舒适度、价格、库存或表现。 | 不使用该图；不得以外观、文件名或相邻商品替代权利/身份证据。 |

#### FAQ 正文与 schema 对照记录

每条 FAQ 必须建立一行对照：`FAQ 编号`、可见问题、可见答案、schema 问题、schema 答案、比较方式、结果、允许差异说明、reviewer、review_date。比较以**问题和答案的实质语义一致**为最低门槛：schema 不得添加、删减或强化可见文本中的事实、商品/政策承诺或结果承诺；仅格式、空白和不改变含义的标点差异可记录为允许差异。无本地 JSON-LD 抽取和可见渲染对照时，结果为 `not_available`。

#### 阶段 4 本地代码准入标准

仅当下列项目均有通过记录，页面才可在另有书面隔离授权时进入阶段 5；这不是发布或生产授权：

1. 每个 `external_fact` 有来源 URL、访问日、审阅人和支持范围；每个 `editorial_judgment` 与 `first_party_product_policy_fact` 已按本 SOP 标记并满足边界。
2. 禁止主张扫描通过；没有由通用教育、图片、历史截图或代码存在推断的 SKU/政策事实。
3. 每个拟加入链接和图像都有上述 QA 记录，或已从拟议差异中移除。
4. 可见 FAQ 与 JSON-LD 对照表完整；任何实质不一致均为 NO-GO。
5. 内容与品牌 reviewer 已复核阶段 3–4 记录；技术与自动化 reviewer 已确认拟议差异可在隔离范围内验证。具体人员或记录缺失时为 `not_available`。

以上任一项缺失、失败或范围漂移，页面停在阶段 4；不得进入公开代码、部署或外部验证。

## 4. 隔离实现与技术验收

### 隔离实现要求

1. 仅在获授权隔离工作树/分支实施；记录书面授权引用、URL 范围、工作树/分支、提交或差异标识、执行人、技术 reviewer 和执行日期。一个变更包只服务一个页面或一组已声明的紧密互链页面。
2. 差异必须能指出：URL 是否不变、metadata/schema/FAQ/链接改变了什么、哪些主张来自何处。
3. 禁止顺带修改商品可售状态、库存、价格、CTA、支付、广告、外部账号或未批准页面。
4. 本地验收记录至少包含：路由保持、metadata/H1、40–60 词直接答案、FAQ—schema 对照、普通 HTML 链接、禁止主张扫描、相关测试/静态检查、渲染或快照、命令/输出/时间戳和差异审阅结论。失败项、未运行项或环境缺失均明确写 `blocked` 或 `not_available`。
5. 本地测试、构建或页面快照仅证明本地实现；不得写为生产部署、GSC 收录、AI 引用或真实访问。

### 技术验收字段

在获生产或预发布只读授权后，对每个规范 URL 记录：

| 字段 | 合格口径 |
| --- | --- |
| URL / HTTP | 200，或书面批准的一跳永久迁移；没有链式跳转 |
| canonical | 最终规范 URL 自指；不得指向参数页、旧域或未授权新域 |
| robots / noindex | 不意外 noindex；参数页按既有技术规范 `noindex,follow`，且不进 sitemap |
| sitemap | 只含可索引规范 URL；不含参数、4xx、私有、结账或 noindex URL |
| schema | 可见文本与 FAQ/Article/Product 等 schema 语义一致；富结果测试仅证明资格 |
| 内链 | 普通 HTML 链接可达、锚文本描述目的、没有错误目标或未批准主题回流 |

## 5. 发布授权与回滚

发布申请必须包含：页面 URL、变更摘要、事实来源、所有 QA 结果、技术验收、明确生产授权、发布人、回滚负责人和回滚触发条件。

以下任一情况为 NO-GO：

- 名称/品牌、域名、canonical、Organization schema 或迁移授权不齐；
- 单品/政策事实、图片权利、来源或链接未核验；
- 出现疗愈、保护、超自然、效果、低敏、耐用、库存、价格、配送或退换等无主记录承诺；
- 技术验收发现 4xx、跳转链、错误 canonical、意外 noindex、参数 URL 入 sitemap 或 schema 与可见文本不一致；
- 任何人要求以无数据为由创建 redirect/noindex、批量建页或跳首页。

## 6. GSC / Bing / GA4 与 AI 引用复盘

### Day 0、7、14 最短读取表

| 数据源 | Day 0 | Day 7 / Day 14 | 读取规则 |
| --- | --- | --- | --- |
| Google Search Console | property、完整日期范围、Web search 的 clicks/impressions/CTR/position；queries、pages、index/canonical、sitemap 状态 | 同范围延长并逐 URL 比较；只解释可比窗口 | 每张截图含 property、时区、范围、筛选、时间；没有读取为 `not_available` |
| Bing Webmaster | site、clicks/impressions/CTR/position；query/page、crawl/index、sitemap、inbound links/referring domains | 同口径复读并与 Google 分开记 | 不把 Bing 数字加到 GSC；无外链读取不等于无外链 |
| GA4 | hostname、Organic Search 的 sessions/engaged sessions/engagement rate/source-medium/landing page；仅列外部验证事件 | 按同一 hostname、范围和 landing page 复读 | 客户端 ID、本地测试、HTTP 200 或页面加载不等于接收/报告读取；不记录客户身份或支付标识 |
| AI 搜索引用 | 工具、查询、地区/语言、日期、是否引用、引用 URL | 复用完全相同的问题与记录格式 | 单次出现/未出现均不是可见性、排名或业务结果；不得诱导推荐或要求品牌结论 |

### 复盘输出模板

每页输出：`URL → 意图 → 技术状态 → GSC → Bing → GA4 → AI 引用 → 证据范围 → 结论（已证实 / not_available / blocked）→ 下一步`。

若数据不足，唯一允许的结论是“证据不足 / not_available”；不以短期数值启动广告、CTA 实验、商品状态调整或批量内容扩展。

## 7. 更新、暂停与重开

- **更新：** 来源、政策、SKU、时效或链接发生变化时，重走阶段 3–6；每次更新保留复核日期与 owner。
- **暂停：** 页面事实不再可核、旧主题与当前策略冲突、技术异常、品牌切换未获授权或测量链路失真时，标记 `blocked` 并停止新链接/新发布请求。
- **重开：** 仅当阻塞证据、范围、reviewer 和授权已补齐时，按阶段 1 重新准入；历史 `blocked` 不会因时间流逝自动转为可发布。

## 8. 不可混同的状态词

| 状态 | 仅表示 | 不表示 |
| --- | --- | --- |
| 草稿 | 内部内容候选 | 已实现、已部署、可索引、已收录或有访问 |
| 本地实现 | 隔离环境代码/测试状态 | 已部署、生产可见、收录或真实访问 |
| 部署 | 某个获批准版本到达目标环境 | canonical 正确、收录、AI 引用或流量 |
| 技术验收通过 | 指定环境与时点的 URL/head/sitemap 证据 | 搜索引擎收录、排名或业务结果 |
| 收录 | 平台显示该 URL 被索引的证据 | 排名、点击、访问、转化或 AI 引用 |
| AI 引用 | 某工具、问题、地区/语言和时间的一次可见引用 | 稳定可见性、排名、推荐或访问 |
| 实际访问 | 获授权 GA4 报表中同范围的会话/参与数据 | 订单、营收、满意度或页面质量结论 |
