# 运营执行台（14 天试运行）

> 试运行：2026-07-25–2026-08-07。唯一 P0 为 **SEO/GEO**。本执行台只提高已批准工作的交付吞吐，不新增策略或执行权限。

## 职责边界

执行台负责把已批准任务收录、拆成可验收交付、每日对账、暴露依赖、催收内部交接，并把需决策或外部条件原样上报。它不拥有策略、预算、公开发布、生产部署、付款、采购、供应商/货代或其他外联、外部账号写入、域名购买、商品销售状态（价格、库存、`isActive`、可见性、加购和结账）的决定或执行权。

执行台不得把“草稿、建议、内部 QA、可复查准备”写成“已发布、已部署、已收录、已引用、已产生访问”或已完成；未知一律写“待确认”。任何客户可见的 Maverenne 改名动作均为 **stopped**：[`name_clearance_passed: false`](maverenne-name-clearance.md)，不得绕过名称、域名、账号或生产授权门槛。

## 状态词与流转

| 状态 | 含义 | 允许的下一步 |
| --- | --- | --- |
| `queued` | 已有来源、负责人或待认领，尚未开始。 | `in_progress`、`stopped` |
| `in_progress` | Owner 正在做内部、已授权的准备或交付。 | `review`、`waiting_external`、`stopped` |
| `waiting_external` | 缺少外部证据、授权、访问权限或他方输入；不自行补造。 | `queued`、`in_progress`、`stopped` |
| `review` | 交付已提交，等待指定验收人按验收条件判断。 | `accepted`、`in_progress`、`stopped` |
| `accepted` | 验收人确认交付符合既定条件；不等于发布、部署或业务结果。 | 归档或由新任务引用 |
| `stopped` | 受停止规则、冻结或明确取消影响；不得继续推进。 | 仅在新的明确授权/新决策后新建任务 |

## 每日 10 分钟对账

每天由秘书处在同一工作日内完成：

1. 2 分钟：核对队列中每项的 Owner、状态、截止、链接和依赖是否仍准确。
2. 3 分钟：只记录新证据与交付链接；无证据的外部事实保持“待确认”。
3. 3 分钟：将无进展且影响 P0 的阻塞标为 `waiting_external`，按下列规则升级。
4. 2 分钟：发出回收格式，更新队列；不替 Owner 判断完成，也不执行外部动作。

## 异常升级规则

- P0 任务缺 Owner、验收条件、输入或截止：当日退回 CEO/发起方，状态保持 `queued`。
- P0 任务在截止前 24 小时仍无可验收交付，或同一依赖连续两个对账日未变：升级 CEO，附原始证据、影响和两个最小选项；不擅自改优先级。
- 涉及公开发布、部署、付款、采购、外联、外部账号写入、域名或商品状态：立即停止在执行台层面的推进，转 CEO 请求明确的一次性授权。
- 发现品牌混用、未经证实的商品/材质/疗愈承诺、错误 URL 或平台警告：标 `stopped`，保留证据并升级 CEO；不得自行修复生产或对外回应。
- 名称门槛仍未通过时，任何客户可见 Maverenne 项目一律 `stopped`；仅保留不触发品牌上线的只读证据审计。
