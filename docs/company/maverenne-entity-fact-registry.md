# GEO 实体与事实注册表（内部）

> 状态快照：2026-07-26；用途：为 AI 搜索摘要、结构化数据、站内文案与对外答复提供可审计的事实边界。本文不是公开内容、法律意见、供应商确认或经营证明；不得以本文替代逐 SKU、逐订单或逐平台复核。

## 使用规则

- `verified`：有可复核的一手证据，且该证据足以支持本表限定的表述；不代表未列出的经营事实也已验证。
- `proposed`：设计、计划、代码配置或公开页面写有该内容，但尚无独立经营/履约/授权验证。
- `unknown`：仓库和已列材料不足以断言；不得补写为事实。
- `contradicted`：来源间相互冲突，或某来源明确否定该断言；停止对外使用，直至复核。
- 复核日期是最晚复核日；发生供应商、价格、库存、域名、政策、支付、主体或平台状态变更时，须立即复核。
- “可公开引用”只表示在当前证据下可以如何谨慎表达，不代表可复制到广告、Schema、AI 摘要或合同；其中 `否` 为禁止，`条件式` 必须同时保留限定语。

## 复核与升级清单

1. 法务补入公司主体的官方登记、商标意见/检索结果及权利主体；在此之前不得发布任何“公司/商标”断言。
2. 域名管理员以注册商后台和生产部署记录确认唯一正式域名，并消除 `mythrealms.com` 与 Vercel URL 的冲突后再允许引用。
3. 供应商负责人为每个 SKU 收集可追溯的原始链接、主体、书面图片授权、材质/尺寸/重量/变体、采购价、实时库存、发货时效与售后规则；Turquoise Leaf 还须先锁定实际发货版本。
4. 运营负责人用真实、经授权的订单、物流和退款记录验证配送/退换实际履约；代码和政策文字在此之前仅为声明。
5. 社媒负责人导出各平台已登录后台的账号归属与状态；不得用 URL 可访问性、搜索结果、截图或策略文档替代。
6. 内容负责人为每条通用珍珠知识补入可公开引用的权威教育来源；任何 SKU 材质声明必须回到该 SKU 的高强度证据。
