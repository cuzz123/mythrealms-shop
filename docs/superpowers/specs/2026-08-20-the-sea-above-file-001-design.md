# 《倒悬之海》FILE 001 设计规格

日期：2026-08-20

状态：创意方向已批准，待用户审阅正式规格

项目：Maverenne TikTok 原创世界观序章

片名：`FILE 001 — THE PEARL THAT ANSWERED / 档案 001：回应她的珍珠`

## 1. 目标

制作一部能够独立成立的竖屏黑暗奇幻微电影，用一个从未在 Maverenne 内容中出现过的世界法则，在第一秒制造认知冲突，并把观众引向主页继续寻找“潮汐档案”。

首片的首要目标依次为：

1. 让陌生观众在首帧发现现实规则被破坏：雨水由地面落向天空。
2. 在前三秒建立一个无需背景知识也能理解的问题：为什么必须在逆雨发生时摘掉珍珠？
3. 在片中将真实 Maverenne 珠宝变成叙事核心，而不是后贴的商品展示。
4. 用结尾身份反转制造主页访问动机，不在首片强行销售。
5. 建立可延伸到耳环、项链、手链和戒指的原创内容体系。

“爆款”不可承诺。本项目以首秒停留、平均观看、完播、复看、评论问题质量和主页访问率作为验证指标。

## 2. 创意定位

### 2.1 一句话世界观

海洋悬在天空之上；珍珠是天海巨物遗失的记忆，而佩戴珍珠的人正在被它们寻找。

### 2.2 核心传播句

> IF THE RAIN FALLS UP, REMOVE EVERY PEARL.
> 如果雨水向上落，摘掉身上所有珍珠。

这句话必须同时具备警告、未知规则和立即可视化三个功能。它是 FILE 001 的主传播句，也是缩略图、开场字幕和发布文案的核心。

### 2.3 风格边界

作品应呈现“美丽但令人不安”的黑暗史诗感，而不是血腥、丧尸、怪物袭击或普通超能力广告。

允许：

- 宏大尺度差异、未知生物局部、记忆消失、失重、逆向水流。
- 克制的身体异常，例如眼睛虹膜逐渐呈现珍珠质感。
- 真实皮肤、真实街道、真实天气和可验证的物理方向。

禁止：

- 血液、伤口、皮肤破裂、寄生虫式身体恐怖。
- 完整展示巨物全貌，削弱未知感。
- 泛滥粒子、魔法光束、超级英雄姿势或游戏技能特效。
- 将 Maverenne 描写为邪教、危险组织或欺骗消费者的品牌。
- 在生成画面中直接生成文字、Logo或产品价格。

## 3. 世界法则

### 3.1 倒悬之海

天空上方存在一整片海洋。海面朝向城市，却被未知力量悬停。人类可从地面看到海水、海底光斑和横跨城市的巨物阴影。

正常天气中，倒悬之海看似遥远；当它接近地面时，首先出现“逆雨”：地面积水和雨滴开始向天空移动。

逆雨是世界中人人认识的灾害警报。因此 FILE 001 中的普通行人会立刻摘下珠宝逃离，无需旁白解释。

### 3.2 母体

天海中的远古巨物统称“母体”。FILE 001 不说明它们的来源、数量或目的，只建立三项事实：

1. 它们的尺度足以遮蔽一座城市。
2. 它们能通过珍珠寻找地面上的人。
3. FILE 001 中的母体错误地或有意地称女主为“母亲”。

FILE 001 只展示母体的移动阴影和一只巨眼，不展示身体全貌。

### 3.3 珍珠与记忆

珍珠不是普通魔法电池，而是母体遗失或主动投放的记忆容器。

- 珍珠选择佩戴者，而非被佩戴者真正占有。
- 使用珍珠能力会使佩戴者失去一段个人记忆。
- 被取走的记忆进入珍珠，使其虹彩更加明显。
- 佩戴者忘记自己的名字时，将发生“归潮”；FILE 001 只提及概念，不展示结果。

女主在 FILE 001 中已经失去一段关于童年女性亲属的记忆，但她尚不知道代价来自珍珠。

### 3.4 珠宝能力分类

该分类用于后续档案保持一致，不在 FILE 001 中完整讲解：

| 珠宝类型 | 世界功能 | 视觉语言 |
| --- | --- | --- |
| 耳环 | 听见母体、接收记忆、打开短暂空间通道 | 声音抽空、空间回声、两侧不对称波纹 |
| 项链 | 改变局部重力与潮汐方向 | 水柱、悬浮织物、重力边界 |
| 手链 | 束缚巨物、建立保护边界 | 环形水印、收紧的光学折射、空间止动 |
| 戒指 | 封存、交换或删除记忆 | 手部接触触发闪回、影像缺帧、人物从记忆中褪去 |

FILE 001 只启用耳环的“听见”和“接收记忆”两项能力，避免首片规则过载。

## 4. 主角与产品

### 4.1 女主

女主为 25–35 岁成年女性。她不是战士，也不在开场展示超能力。第一部序章中，她只是唯一没有及时摘下珍珠的人。

视觉身份：

- 深色湿发或受雨水影响的自然发型。
- 真实皮肤纹理，克制妆容。
- 象牙白或灰白结构化外套，避免飘逸仙女裙。
- 表演以观察、迟疑、识别声音为主，不尖叫、不夸张惊恐。
- 眼睛颜色和面部结构跨镜头严格锁定。

### 4.2 主遗物

FILE 001 使用 `The Baroque Orbit — Earrings`，产品路径为 `/products/new-series-baroque-pearl-hoops`。

必须保持的产品结构：

- 金色圆环耳扣。
- 耳扣正面的绿色小石。
- 单一连接环。
- 不规则白色巴洛克珍珠吊坠。
- 珍珠末端的小金珠。

叙事选择巴洛克珍珠，是因为不规则外形既能成为母体“记忆器官”的视觉证据，也与现有 TikTok 数据中 `Not perfectly round. That's the point.` 的较高注意质量方向一致。

## 5. FILE 001 叙事结构

目标成片长度为 28–34 秒。时长可以在剪辑中缩短，但不得为了填满时长增加解释性镜头。

### 段落一：规则破坏（0:00–0:02）

英伦老城街道正在下雨，所有雨滴却从地面向天空倒流。地面水花先出现，再向上还原成雨滴。普通行人匆忙摘下珠宝。

女主静止在逆流人群中。

后期字幕：

> IF THE RAIN FALLS UP, REMOVE EVERY PEARL.

首帧不得出现 Logo、产品名称或渐显。观众必须在静音状态下识别“雨的方向不对”。

### 段落二：珍珠回应（0:02–0:06）

女主伸手准备摘下耳环。珍珠不粘连皮肤、不发生生物变形，而是以物理上不可能的方式主动转向天空。

城市环境声在珍珠转向的瞬间被抽空，只保留来自珍珠内部的低频心跳。女主停止动作。

### 段落三：世界揭晓（0:06–0:11）

街面积水离地形成上升水柱。镜头沿其中一根水柱抬升，揭示覆盖整座城市的倒悬海洋。

远处一条无法看清全貌的巨大阴影从海中经过，遮住自然光。

广播声：

> It heard someone.
> 它听见了某个人。

### 段落四：母体接近（0:11–0:18）

倒悬海洋底部出现一道细长暗缝，随后揭示为正在睁开的巨眼。虹膜具有与女主巴洛克珍珠相同的不规则纹理和冷虹彩。

城市玻璃、路牌水珠和橱窗吊灯同时向天空轻微震动，确认母体影响整个空间，而不是女主的幻觉。

珍珠中传出儿童般的声音：

> I remember you.
> 我记得你。

### 段落五：记忆代价（0:18–0:25）

女主闪回童年：同一条街道、年幼的自己，以及一位戴着相同耳环的成年女人。成年女人的脸先被上升海水折射，再从记忆中完全抹去。

闪回总时长不超过两秒，并通过声音而非长旁白建立情感。

女主问：

> Who are you?
> 你是谁？

这句话同时证明她失去了相关记忆，并让观众产生身份问题。

### 段落六：身份反转（0:25–0:31）

巨眼没有回答。女主耳边的珍珠以低沉、非人类的声音说：

> Mother.
> 母亲。

城市中不同人物身上的珍珠依次亮起，光点向远处扩散。女主的一只虹膜开始呈现珍珠质感，但仍保留人眼结构。

反转含义：不是珍珠在寻找母体，而是母体把女主认作自己的母亲。FILE 001 不解释这种识别是否正确。

### 段落七：档案结尾与循环（0:31–0:34）

切黑并显示后期文字：

> THE SEA HAS CHOSEN AGAIN.
> 倒悬之海，再次作出了选择。

随后仅显示：

> MAVERENNE // RECOVERED TIDE FILE 001

一滴水从黑暗中向上穿过镜头，声音和运动衔接回开场逆雨，使视频自然循环。

## 6. 视觉系统

### 6.1 色彩

- 建筑与服装：石灰岩灰白、风化米色、湿冷深灰。
- 天海：风暴青、深海墨蓝、低饱和冷绿。
- 珍珠：白色冷虹彩，只在关键反转提高亮度。
- 金属：旧金色、小面积暖色，不使用大面积橙色轮廓光。

禁止通用“青橙电影滤镜”。人物肤色必须自然，珍珠白平衡不得漂蓝。

### 6.2 巨物尺度

巨物尺度通过环境反应证明：城市阴影移动、玻璃震动、水柱偏转和自然光被遮挡。不得依靠画面中放入一只缺乏参照物的大眼睛来假装宏大。

### 6.3 摄影

- 竖屏 9:16，4K母版，24fps电影运动感。
- 首镜使用接近地面的 28–35mm 广角，让逆雨和人群动作同时可读。
- 产品近景使用 85mm 微距感，完整耳环在关键帧保持清晰。
- 世界揭晓采用一次有明确起止点的上抬，不做无目的无人机巡航。
- 母体镜头以锁定或极慢运动为主，让环境运动承担恐惧。
- 单镜头只设置一个主要摄影运动和一个主要超现实事件。

## 7. 声音系统

声音必须在无流行音乐的情况下独立成立。后期可测试极低音量配乐，但不得依赖热门歌曲制造节奏。

声音顺序：

1. 真实雨声中混入反向吸水声。
2. 珍珠转向天空时，城市环境声瞬间抽空。
3. 珍珠内部出现近距离、干燥的低频心跳。
4. 世界揭晓时加入极远、无法判断来源的海洋低鸣。
5. `I remember you` 使用儿童般近讲声；`Mother` 使用宽广低沉声，两者不得像同一角色。
6. 结尾上升水滴的声音与开场第一帧无缝衔接。

对白和文字均准备英文主版本与中文字幕版本。面向英文 TikTok 发布时，画面内只保留英文主字幕，中文作为独立导出版本，避免双语同时拥挤首屏。

## 8. 制作架构

不得要求单次视频生成完成整部 28–34 秒成片。制作应分为可独立验证的层：

1. **角色与产品身份层**：女主标准肖像、服装、耳环结构和关键表情。
2. **环境规则层**：英伦街道、逆雨方向、倒悬海洋空间关系。
3. **巨物层**：阴影、巨眼和环境尺度反应，保持未知而非完整建模。
4. **记忆层**：童年闪回和人物面孔消失，使用独立视觉语法。
5. **声音层**：环境、心跳、低鸣、两种声音身份和循环点。
6. **后期层**：剪辑、字幕、档案标识、调色、合成和最终循环。

每层都先通过静帧或短片段审核，再进入组合。任何一层失败时只返修该层，不重生成已经通过的产品或人物身份。

## 9. 质量门禁

### 9.1 首秒门禁

- 静音观看第一帧，能明确判断雨水正在向上运动。
- 缩略到手机信息流大小，女主和逆雨仍可读。
- 首帧无 Logo、渐显、空镜或说明性片头。

### 9.2 世界连续性门禁

- 所有水滴、水柱、织物和松散物件遵循同一重力方向。
- 倒悬海洋在镜头之间保持一致高度、光向和海面朝向。
- 巨物经过时，阴影、声音和环境反应时间一致。

### 9.3 人物与产品门禁

- 女主脸型、眼睛、发型和服装跨镜头一致。
- 耳环的金环、绿石、连接环、巴洛克珍珠和末端金珠无增减或变形。
- 耳环在至少三个关键画面完整可读，但不得每个镜头都变成商品特写。
- 珍珠眼变化保持真实人眼结构，不出现多瞳孔、融化或塑料CG效果。

### 9.4 盲看门禁

向不了解设定的观看者展示：

- 前3秒后，首要问题应接近“为什么雨往上走”或“为什么要摘珍珠”。
- 前11秒后，应理解天空中存在海洋和大型未知生物。
- 结尾后，应提出“她为什么被叫作母亲”或希望查看下一份档案。

若观看者只评价“画面很美”而没有提出上述问题，视为叙事失败。

### 9.5 技术门禁

- 最终4K母版无可见压缩块、插帧重影、边缘融化或首饰漂移。
- 手机扬声器能听清关键声音，耳机播放无低频削波。
- 字幕位于 TikTok 安全区，不被用户名、标题和操作按钮遮挡。
- 英文字幕语法和中文翻译分别校对。
- 最终首尾循环无黑帧、音频点击或运动跳变。

## 10. 发布与验证

主页统一包装为 `RECOVERED TIDE FILES / 失落潮汐档案`，FILE 001 发布时不使用 `Shop Now` 或价格文案。

英文发布文案建议：

> The warning was simple: if the rain falls up, remove every pearl. She was one second too late.
> FILE 001 — The Pearl That Answered.

中文发布文案建议：

> 警告只有一句：如果雨水向上落，摘掉身上所有珍珠。她迟了一秒。
> 档案 001：回应她的珍珠。

置顶评论：

> Why did it call her “Mother”? FILE 002 will begin with the missing memory.

第一轮不同时修改开场、片长、文案和声音。只为前2秒准备两个开场剪辑版本：

- A：先出现逆雨，再出现警告文字。
- B：先出现警告文字0.2秒，随后硬切逆雨。

以至少 300–500 次有效播放作为方向性判断起点。核心指标：

- 前1–2秒留存相对现有账号基线显著提升。
- 平均观看时间达到成片长度的35%以上。
- 完播率达到15%以上，并观察复看迹象。
- 评论中出现关于世界规则、女主身份或下一档案的问题。
- 主页访问率达到2%以上。

样本量不足时不得将指标记为0；应标记为 `not_available` 或 `insufficient_sample`。

## 11. FILE 001 范围外

以下内容留待首片验证后处理，不进入 FILE 001 制作：

- 母体完整造型和物种分类。
- 阵营、战争、宗教或完整历史年表。
- 女主真实姓名与“母亲”身份的最终答案。
- 全季剧本、长篇动画或真人短剧选角。
- FILE 002 之后的具体产品映射。
- 付费广告、商品价格或落地页转化版本。

## 12. 完成定义

FILE 001 只有在以下条件全部满足时才可发布：

1. 设计中的七个叙事段落均可在成片中辨认，且无多余解释镜头。
2. 首秒、世界连续性、人物产品、盲看和技术门禁全部通过。
3. 英文主版本与中文字幕版本均完成校对和安全区检查。
4. 4K母版、TikTok上传版、封面、发布文案、置顶评论和指标记录表齐备。
5. FILE 001 结尾能自然循环，并提供真实的主页探索动机。
