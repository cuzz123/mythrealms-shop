# Director Board Preview Batch — Design

## Goal

Create three review-only master director boards before producing any A–G continuity packs, Seedance first frames, prompts, clips, edits, or posts. The founder reviews visual direction first; downstream production stays blocked until explicit approval.

## Shared board system

- One hybrid template across the first batch: the production clarity of the light reference board plus the black-and-warm-gold luxury finish of the dark reference board.
- Landscape 16:9 presentation board.
- Clear modules: project header, fictional adult model reference, environment/set master, product anchor/detail, spatial/light note, and six sequential story frames.
- English display copy only, kept minimal to reduce generated-text errors. No public brand claim, price, material, inventory, delivery, performance, or rights claim.
- Each six-frame story has causal continuity rather than six unrelated poses. Each frame has one primary camera move and a visible start/end state.
- These boards are visual concepts, not product-fact evidence and not publication assets.

## Batch concepts

- Product/reference boundary: use the existing internal shot-template frames only as visual structure references; the board remains concept-only.

## Product-fidelity gates

- Product reference is authoritative; layout references transfer board design only.
- Do not add, delete, symmetrize, simplify, or reinterpret visible product geometry.
- If a product cannot be rendered consistently within a board, mark that panel as an abstract silhouette/product-reference placeholder rather than inventing structure.
- No board can unlock downstream work by itself.

## Review criteria

The founder reviews: model appeal and distinctiveness, scene suitability, product recognizability, narrative continuity, camera variety, brand fit, and overall luxury/editorial quality. Approval can be per board; rejected boards are revised without starting downstream production.
