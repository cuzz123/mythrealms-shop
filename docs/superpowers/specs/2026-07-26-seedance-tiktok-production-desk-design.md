# Seedance 2.0 TikTok 视频制作台设计

日期：2026-07-26

状态：创始人已确认设计，待规格复核

适用范围：内部素材准备、人工生成、人工剪辑与人工发布支持

## 目标

在不新增永久部门、不恢复自动剪辑、不操作外部账号的前提下，建立一条适合创始人当前能力与小云雀额度的 TikTok 视频生产流程：每天使用 3 个 4 秒 Seedance 2.0 生成名额，形成一条 7–8 秒成片候选和一条备用钩子，并通过持续复盘提高动态自然度、可剪辑性和内容有效性。每个分镜在进入提示词交付前必须具备足够的首帧、人物、场景和产品参考；缺失的可生成输入由内置图像生成能力按需补齐。

本项目不改变公司现行优先级。SEO/GEO 仍为唯一 P0；TikTok 视频制作台属于内容与品牌会话下的支持工作线。

## 组织方式

不新建永久部门。自实施日起试运行 14 天“TikTok 视频制作台”，归内容与品牌会话，秘书处仅负责交付协调。

制作台负责：

- 每日 3 条 Seedance 2.0 提示词；
- 三段素材的连续性设计；
- 剪映时间线、屏幕文案、声音与卡点建议；
- 生成结果 QA、失败原因和下一轮单变量调整；
- 成功动作与失败模式的知识库沉淀。

创始人负责：

- 将提示词和指定素材手工提交给小云雀；
- 下载并保存三段生成结果；
- 在剪映中手工剪辑；
- 通过 AdsPower 登录 TikTok 并手工发布；
- 回传原始片段、成片和平台可读指标。

制作台不得代为登录、发布、投放、付款、采购、外联或修改商品状态。

## 每日额度方案

采用已批准的方案 C：两段成片加一个备用钩子。

| 生成名额 | 叙事任务 | 预期剪辑用途 |
| --- | --- | --- |
| 1 | 主钩子：首个 0.5 秒内出现可感知的空间、人物或物体变化 | 截取约 2.5–3.5 秒作为开场 |
| 2 | 商品或情绪回应：延续运动方向、光线或视觉动机 | 截取约 3–4 秒作为回应和落点 |
| 3 | 备用钩子：只改变一个测试变量 | 存入素材库，替换失败片段或进入下一轮测试 |

每日目标是 1 条 7–8 秒成片候选和 1 条备用钩子。14 天理论上产生 42 个原始片段、14 条成片候选和 14 个备用钩子；只有完成剪辑、人工确认并取得真实平台记录的内容才能标记为正式成片或已发布。

## Seedance 提示词 v3

每条提示词按以下六部分组织：

1. 参考职责：明确人物、商品、场景或动作分别由哪个输入承担；
2. 开场状态：动作在第 0 秒已经发生，避免站定等待；
3. 核心事件：4 秒内完成一件有动机的事情；
4. 镜头契约：景别、方向、速度变化、主体关系和终点构图；
5. 物理响应：头发、衣料、首饰、光影、遮挡和景深的因果运动；
6. 最小身份锁：仅保留 3–5 个决定商品身份的结构特征和必要排除项。

v3 不再把以下表达作为默认模板：

- 机位基本锁定；
- 只允许 2%–6% 的移动；
- 眨眼一次；
- 轻摆一次后停稳；
- 全部停住；
- 将 4 秒切成多个机械微动作。

v3 优先使用以下运动语言：

- 前景擦镜或短暂遮挡后揭示主体；
- 人物进入或离开光区；
- 镜头被人物动作带动改变位置；
- 步伐、转身、衣料和首饰产生连续惯性；
- 焦点在有明确叙事动机时交接；
- 动作结束后形成区别于首帧的新构图。

首帧应尽量选择“动作前一刻”或“动作进行中”的非平衡状态，不再默认使用已经完成广告构图的静态美图。

## 输入资产完整性门槛

每个分镜在进入每日三个小云雀名额前，先登记四类输入：

1. 首帧：与提示词开场状态一致的精确 `@Image1`；
2. 人物：需要身份连续性时，至少有一张清晰身份图；涉及明显转身、走位或侧背面时，补正面、三分侧和侧/背面参考；
3. 场景：至少有一张能说明空间关系、光向和运动路径的场景主参考；
4. 产品：至少有一张可核对整体结构的产品图；产品特写或明显角度变化时，再补对应细节或角度参考。

缺失资产按以下规则处理：

- 默认使用内置图像生成工具逐张生成，不使用 CLI/API 回退；
- 首帧、人物视图和场景图可根据已有已批准参考生成，保存为新版本，不覆盖原文件；
- 人物完全没有身份来源时，可以生成一位新的虚构成年模特，但必须明确标为 AI 生成身份，不得暗示真实客户或代言人；
- 产品辅助视图必须以现有可核对产品图为结构来源，保持关键几何关系；若连一张可靠产品来源图都没有，则不得凭空发明商品，相关分镜继续阻塞；
- 每张生成图必须保存最终提示词、输入图职责、输出路径、生成日期、对应分镜和人工验收状态；
- 生成图只解决视觉输入完整性，不自动证明商品材质、规格、商用授权、样品一致性或可售事实；
- 项目要使用的最终图片必须复制到工作区中的对应镜头模板目录，不能只留在内置工具默认目录。

输入资产 QA 至少检查：人物身份一致、手耳颈等解剖结构、产品数量和几何、佩戴位置、空间透视、光向、9:16 裁切安全区，以及是否包含文字、logo、水印或未授权第三方标识。

## 两段连续性

主钩子和回应镜头至少共享一种连续性：

- 相同运动方向；
- 相同人物或商品；
- 相同光线变化；
- 相同前景物或场景入口；
- 动作结果与下一镜头开场形成因果关系。

不得仅依靠相似色调把两个无关片段拼接为一条视频。

## 剪映基础模板

- 0.0–0.4 秒：直接进入最强动作，不使用淡入；
- 0.4–3.2 秒：主钩子；
- 约 3.2 秒：沿动作、遮挡、视线或光线方向硬切；
- 3.2–7.0 秒：商品或情绪回应；
- 7.0–8.0 秒：干净落点或一句短 CTA；
- 全片只使用一条音乐、一种字幕系统和至多一次轻音效；
- 不默认使用模板转场、闪白、旋转、连续变焦或大量贴纸；
- 屏幕文案最多两句，每句尽量不超过六个英文单词。

## Blender 与 AE 的定位

Blender 和 AE 默认暂停，不作为每日流水线。只有同时满足以下条件才允许提出一次受控对照：

1. 同一重要动作使用首帧和提示词连续失败三次；
2. 失败原因明确属于摄影机路径、人物走位或焦点交接；
3. 使用低成本灰模或 2.5D 控制片即可表达；
4. 与无控制视频版本使用同一首帧和同一目标做配对测试；
5. 一轮对照未显示清晰提升时立即停止，不继续堆叠控制资产。

现有 Blender 与 AE 资产保留，不删除，也不把网上教程的效果视为 MythRealms/Maverenne 已验证结果。

## QA 与复盘

每个原始片段至少检查：

- 前 0.5 秒是否已有明显运动；
- 动作是否有起因、推进和新状态；
- 人物、首饰和场景是否处在同一空间；
- 产品关键结构是否保持；
- 是否出现换脸、增生、漂浮、贴图边缘或物理失真；
- 是否存在可剪切的运动节点和干净落点；
- 是否包含未核验材质、价格、库存、履约、低敏或功效承诺。

失败时一次只调整一个变量。优先顺序为：开场状态、动作幅度、镜头关系、参考输入、场景；不得用不断增加形容词掩盖根因。

平台复盘只使用真实可读指标。至少记录发布时间、视频 URL、播放量、平均观看时长、完播率、互动和主页访问；不可读字段标记为“待确认”，不得填 0 或推测。小样本不用于宣布商品需求或渠道胜出，只用于选择下一轮镜头和开场测试。

## 知识库实施范围

规格复核通过后，实施阶段将：

1. 建立六组镜头的输入资产完整性矩阵，逐条核对首帧、人物、场景和产品参考；
2. 使用内置图像生成工具补齐可安全生成的缺失输入，并把最终选中图复制到对应镜头模板目录；
3. 新建 `video-pipeline/asset-library/obsidian-vault/02-镜头配方/镜头配方｜Seedance 动态叙事动作库 v3.md`；
4. 为 Baroque Orbit、Falling Pearl、Luxury Product Reveal、Moon Disc、Turquoise Leaf、Violet Rain 六张产品镜头卡增加 v3 替换段，不覆盖历史提示词；
5. 保留 `镜头配方｜Seedance 动态叙事动作库 v2.md` 作为历史版本；
6. 新建一张 14 天每日 `3×4 秒` 制作台执行卡；
7. 首日只交付两条连续镜头提示词、一条备用钩子、剪映时间线、文案和 QA 表，不操作小云雀、剪映或 TikTok。

截图中的“Seedance 动态叙事动作库 v2”是公共动作库，不计为第七张产品卡；因此实际需要更新的是六张产品卡加一张公共动作库。

## 验收标准

- 新旧版本均可追溯，旧提示词没有被删除；
- 每个可执行分镜都有可打开的精确首帧和足够的人物、场景、产品参考，缺失项有生成溯源或明确阻塞原因；
- 所有内置工具生成的项目图片已复制到工作区并使用版本化文件名，原资产未被覆盖；
- 每张 v3 配方明确主钩子、回应镜头和备用钩子；
- 每条提示词具有开场状态、核心事件、镜头契约、物理响应、终点和最小身份锁；
- 不包含未核验商品事实或品牌功效承诺；
- 每日卡能由初学者按顺序完成小云雀生成、文件回传、剪映剪辑和手工发布；
- Blender/AE 不进入默认日常路径；
- 所有外部发布、登录、付款和投放继续由创始人控制。

## 试点结束条件

达到以下任一条件时，才评估是否建立独立长期会话：

- 连续两周每周稳定交付至少 5 条合格视频；
- 可验证地每天为创始人节省至少 30 分钟；
- TikTok 已产生可复核的稳定访问或互动信号，需要扩大；
- 镜头配方、剪辑支持和复盘明显挤占内容与品牌会话。

未达到时，制作台并回内容与品牌会话，不新增永久部门。
