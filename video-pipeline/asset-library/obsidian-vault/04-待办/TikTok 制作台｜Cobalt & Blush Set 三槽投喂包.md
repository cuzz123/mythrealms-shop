## 失败重试｜一次只改一个变量

| 失败现象 | 判定 | 下一次只改这一项 |
| --- | --- | --- |
| 画面像静态图，只动了高光或微推 | `Rewrite` | 保持产品锁与场景不变，仅把手的位移重申为 6–7 厘米，或把镜头对角位移重申为 15%。 |
| 多出或少了项链/手链 | `Re-roll` | 保持动作不变，将镜头改为基本锁定，并在首句再次写“始终恰好一条项链和一条手链”。 |
| 组件顺序、颜色分布或比例漂移 | `Re-roll` | 保持动作与终点不变，删除焦点转移，只保留产品锁和单一相机移动。 |
| 手指畸变或重新抓握 | `Re-roll` | 保持产品与镜头不变，把手部动作缩为同一接触点、同一方向、无重新抓握。 |
| 窗帘影不明显 | `Rewrite` | 保持商品和相机不变，仅把纱帘位移改为“下缘横移一个手掌宽度，明暗边界完整扫过两件首饰”。 |
| 手链移动时撞到或覆盖项链 | `Rewrite` | 保持手部速度和相机不变，仅把终点改为“与项链保持约一个手链宽度，不重叠”。 |
| 只有局部小瑕疵且可裁切 | `Fix in post` | 不重生成；记录可用入点与出点，在剪映中裁掉瑕疵段。 |
