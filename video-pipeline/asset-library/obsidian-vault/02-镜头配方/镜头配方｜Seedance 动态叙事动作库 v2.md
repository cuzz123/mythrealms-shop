# 镜头配方｜Seedance 动态叙事动作库 v2

> 这张卡替代旧卡中“眨眼、轻转头、停住”的默认动态逻辑。目标不是把静帧做成 GIF，而是在 4 秒内捕捉一个正在发生、能自然收束的真实瞬间。

## 先这样投喂

1. 上传该镜头的首帧为 `@Image1`；若平台支持，再加产品图为 `@Image2`，只负责锁定首饰结构。
2. 每条只保留 **一个人物主动作** 和 **一个镜头运动**。动作必须有起点、过程、落点，镜头只服务这件事。
3. 不要求模型生成文字、logo、价格或 BGM；均在后期完成。
4. 生成失败只改一个变量：先改动作幅度，其次改机位，最后才改场景。不要往提示词叠加更多形容词。

## 所有提示词共用的结构锁

把以下尾段附在每条提示词后，不要删：

```text
严格保持 @Image1 的同一位成年模特、真实皮肤纹理、服装、发型、首饰数量、首饰几何结构、场景建筑、时间和光向。首饰不是贴图，不要出现抠图边缘、漂浮、变形、复制、额外首饰、额外人物、杯子、桌子、笔记本、花瓶、书本、文字、logo 或水印。动作连续且有重量感；人物和首饰处在同一真实空间。环境声仅保留现场自然声，无配乐、无对白。
```

## 动作语法

| 片段阶段 | 应发生什么 | 不要发生什么 |
| --- | --- | --- |
| 0.0-0.7s | 动作已经开始，首帧即有悬念 | 静止等动作、突然跳切 |
| 0.7-2.6s | 主动作完整推进，首饰因身体或布料惯性产生真实次级运动 | 同时做两种手势、夸张摆拍 |
| 2.6-4.0s | 动作自然落点，给剪辑一个可用停点 | 全员冻结、硬停、回弹 |

## A. 耳环：人物动作型钩子

### A1｜拱门闯入后回眸

**适用：** Baroque Orbit、Violet Rain、白贝三垂耳环。  
**效果：** 不在原地摆头，而是人物已经从拱门阴影走到日光边缘，听见身后动静后半回眸；耳环随步伐和转头完成一次真实摆幅。

```text
@Image1 为首帧。4 秒连续单镜头，镜头在模特侧后方以 50mm 镜头平稳跟随，向前移动约半步，不推近、不绕圈。0.0 秒模特已从石拱门的阴影跨到侧光里，衣料和头发仍带着行走惯性；0.7-2.5 秒她继续向前走两小步，听见身后动静后自然放慢；2.5-4.0 秒她只转动头颈和上半身约四分之一圈，目光从画外扫回镜头附近，耳环因停步与回眸摆动一次后自然收束。焦点始终优先保留靠镜头一侧完整耳环和眼神，背景保持真实景深。
```

### A2｜风把头发吹向耳后

**适用：** 微距肖像、需快速露出单只耳环。  
**效果：** 不用“手拨发丝后静止”，而是风先把发丝吹到脸侧，人物在走动的余韵里顺势将其别到耳后，动作结束时眼神已经落到画外。

```text
@Image1 为首帧。4 秒肩部近景，85mm，镜头沿人物视线方向做一次 6% 的缓慢横向滑移。0.0-0.8 秒一阵自然海风把前侧发丝吹到面颊；0.8-2.7 秒模特顺势抬起同侧手，将整缕头发从耳前带到耳后，手指不触碰耳环；2.7-4.0 秒手沿颈侧自然落出画面，模特把视线越过镜头投向远处，耳环在发丝离开后完成一次清晰、受重力约束的摆动并逐渐稳定。不要摆拍笑容，不要增加第二个手势。
```

### A3｜雨后屋檐下的加速一步

**适用：** Violet Rain、深色服装、湿石庭院。  
**效果：** 用“赶上雨停”的一小步做开场，首饰在湿光中闪现，而非靠灯光扫一遍。

```text
@Image1 为首帧。4 秒中近景，45mm，镜头从拱门内侧向外跟移约一步。0.0 秒模特刚避开屋檐落水，肩膀和衣角仍有加速惯性；0.5-2.2 秒她踩过一小段湿石地，向庭院光源迈出两步；2.2-3.3 秒她停在光影交界处，抬眼看向檐外；3.3-4.0 秒耳环在停步后的余摆中捕住一次紫色反光，脸与耳环同时清晰。雨滴只出现在背景和地面，不能落在首饰上造成结构变化。
```

## B. 项链与链坠：布料和呼吸带动，不靠手指摆弄

### B1｜门洞转身，链坠滞后落下

**适用：** Falling Pearl、珍珠 Y 链、长坠。  
**效果：** 人物从门洞向外转身，衣料先动、链坠后跟，最后落回胸前中心，能把链条真实重量拍出来。

```text
@Image1 为首帧。4 秒半身连续镜头，50mm，镜头从门洞内向右做一次小幅平移，始终保持胸前链坠在画面中央偏下。0.0-1.0 秒模特背对夕光站在门洞边，已经开始把身体从画外方向转向光线；1.0-2.8 秒她完整转过上半身并向外迈一步，亚麻衣料自然掠过胸前；2.8-4.0 秒她停在侧逆光里，Y 形珍珠链坠因转身惯性缓慢回落，最后垂直停在胸前，不能缠绕、缩短、复制或变成其他项链。
```

### B2｜走过镜头，回身接住衣领

**适用：** 珍珠流苏项圈、层叠项链。  
**效果：** 人物不是原地摸项链，而是从镜头前走过后轻按衣领，项链被身体运动带出可读节奏。

```text
@Image1 为首帧。4 秒中景，40mm，镜头以肩部高度侧向跟随人物走过约一米。0.0-2.0 秒模特从画面左侧经过镜头，步伐平稳，项链和流苏随胸腔、衣料与步伐做真实小幅摆动；2.0-3.1 秒她在侧前方减速并回身半步，空闲手只轻压一次衣领边缘，不抓、不拉首饰；3.1-4.0 秒她抬起下巴看向画外，流苏在余摆后收束。镜头不得超过人物，不要环绕。
```

## C. 手镯和手链：让手去做一件事

### C1｜手沿石墙滑行，离墙收势

**适用：** Turquoise Leaf、紫宝石手镯、硬质开口镯。  
**效果：** 手镯不是固定在画面中旋转，而是手掌借石墙带动身体，离开墙时停在光线里。

```text
@Image1 为首帧。4 秒手部与半身镜头，65mm，镜头贴着手的路径平稳向下再微微向前跟移。0.0-0.8 秒佩戴手镯的手背已轻贴粗糙石墙；0.8-2.7 秒手掌和前臂沿墙缓慢滑过一段连续距离，身体同时从阴影走到日光边缘；2.7-4.0 秒手离开墙面，手腕自然翻到约四分之一圈，让手镯落在光里，停在可读的三分之四侧面。手部只有这一次连续动作；手镯保持原有开口、宝石、珍珠和金属比例，不能旋转成闭环或变成链式首饰。
```

### C2｜抬手遮光，再放下视线

**适用：** 手镯、腕表感强的袖口产品。  
**效果：** 自然又有钩子：阳光太强，人物抬手遮光，镜头从脸转到手腕，最后手落下露出产品。

```text
@Image1 为首帧。4 秒上半身近景，50mm，镜头从眼睛焦点缓慢跟到手腕焦点，机位不改变高度。0.0-1.2 秒阳光打进人物眼睛，她自然抬起佩戴手镯的前臂遮住额前光线；1.2-2.8 秒她透过手臂看向远处，镜头在这段时间从眼神拉焦到手腕；2.8-4.0 秒她把手臂慢慢放下至胸前，手镯仍朝镜头可读的一侧，留下稳定落点。不要比心、挥手、转手腕炫耀或增加第二只手。
```

## D. 场景与人物：用位置变化做结尾

### D1｜穿过前景，进入留白 CTA 位

**适用：** 任何景别较大的结尾镜头。  
**效果：** 在镜头里真正换位置，既给产品氛围，也留出后期 CTA，不再只是回头站住。

```text
@Image1 为首帧。4 秒环境主导的中远景，35mm，镜头固定在原地，只做 4% 的缓慢后撤。0.0-1.3 秒模特从前景边缘进入，短暂遮住一部分镜头；1.3-3.0 秒她沿石阶或墙边走向右侧三分位，衣料、发丝和首饰跟随步伐自然运动；3.0-4.0 秒她停在右侧光影交界并把脸转向场景深处，左侧留白保持干净，供后期放 CTA。不要看镜头，不要停在画面中心。
```

### D2｜镜头先过场景，再捕获人物

**适用：** 需要开场反钩子、避免产品特写过多。  
**效果：** 先让空间有动作，人物在画外进入焦点，形成“镜头发现人”的感觉。

```text
@Image1 为首帧。4 秒，35mm，镜头从一段真实前景植被、拱门边缘或纱帘后平稳侧移出来。0.0-1.4 秒前景掠过镜头，场景是清晰的真实空间而非叠加层；1.4-2.8 秒镜头越过前景时模特从画外走进中景，焦点随她进入而落到耳饰或手镯；2.8-4.0 秒她继续走到既定位置并略过镜头视线，镜头停在可剪辑的干净构图。前景不能遮挡首饰到不可读，也不能像前后景抠图。
```

## 生成后验收

- [ ] 0 秒就能看出动作正在发生，而非静态等候。
- [ ] 4 秒内主动作完整结束，最后 0.5 秒有可剪辑的稳定落点。
- [ ] 首饰随真实身体、布料或重力运动，未被手指刻意摆弄。
- [ ] 没有抠图边缘、漂浮首饰、额外道具、人物换脸或场景突变。
- [ ] 镜头只有一个清晰路径，没有推拉摇移同时发生。
