# 镜头配方｜Seedance 动态叙事动作库 v3

## v3 与 v2 的关系

v2 原文和已生成结果全部保留。v3 不把人物当静态展台，而是要求画面从第 0 帧就处于一个有原因的动作中，并在 4 秒内到达不同构图。旧结果可作身份、服装、商品和场景参考，但不得把旧提示词中的微动默认值复制进 v3。

## 每日方案 C

每天只消耗三个 4 秒名额：`main_hook` 负责前 0.5 秒运动，`response` 负责商品或情绪证明，`alternate_hook` 只改变一个开场变量。主钩子和回应镜头剪成一条 7–8 秒候选；备用钩子保留作替换或下一轮单变量测试。小云雀、剪映和发布均由创始人手工执行。

每条可执行提示词第一行固定写 `9:16 竖屏，4 秒，首帧生视频（I2V）。`。每张本地参考图直接使用 `@D:\完整路径\文件名.png` 作为开头，随后说明职责；不得写成 `@Image1 …：D:\路径`，避免创始人再次手工改写。

## 六段提示词契约

每条可运行提示词必须依次写清：

1. **参考职责**：逐一使用 `@D:\完整路径` 说明人物身份、商品结构、场景空间、光向和首帧由哪个输入承担。
2. **第 0 帧状态**：动作已经发生，写出遮挡、重心、朝向、接触点或跨越边界；不从完成姿势起步。
3. **唯一动机事件**：人物正在完成一件真实任务，或环境变化推动画面；四秒只保留一个主事件。
4. **镜头契约**：景别、方向、相对人物的路径、不可越过的轴线和终帧位置。
5. **物理响应**：头发、衣料、链坠、耳饰、阴影或水光只响应主事件，具有延迟和衰减，不自行表演。
6. **终点与身份锁**：写出新构图、干净剪点，以及三至五个可观察商品结构特征。负面约束只保留：身份漂移、几何复制、额外首饰、换脸、商品漂浮、文字、logo、水印。

## 首帧选择规则

- 首帧必须直接显示动作正在进行的证据，例如前景正擦过镜头、脚步已跨过门洞、手掌正离开扶手、身体正越过光界。
- 首帧同时承担身份、空间轴线和光向锁定；商品结构另用可靠全貌图锁定，必要时补细节角度。
- 行走、转身或侧背揭示必须同时提供正面、三分之四和侧面/背面身份支持。
- 首帧若只是一张完成的美照，即使构图漂亮也不进入 v3 主钩子。
- 提示词不重复首帧已清晰显示的环境形容词，只写会改变的关系。

## E. 耳饰动作

### E1｜前景擦镜进入侧脸

- **适用**：耳环、耳坠；需要快速建立人物、空间和近侧耳饰。
- **第 0 帧**：真实前景边缘已覆盖部分镜头，人物从隐藏的三分之四角度迈入，近侧耳朵尚未完全露出。
- **唯一事件**：人物完成一步并进入清晰侧脸；镜头与人物同向越过遮挡，不绕人旋转。
- **镜头**：50–85mm 近景感，沿前景边缘作一次果断横向清障，始终与人物保持同侧，终点落在非居中的近侧耳饰。
- **物理响应**：步伐先改变肩线，发尾和衣领随后，耳饰最后以小幅惯性追随；所有运动来自同一步。
- **商品锁**：锁定耳饰数量、上方连接结构、主垂坠轮廓、点缀位置和佩戴耳侧。
- **剪点**：前景刚完全离开镜头、侧脸和完整近侧耳饰同时可读时硬切。
- **最小负面**：身份漂移、几何复制、额外首饰、换脸、商品漂浮、文字、logo、水印。

### E2｜越过光界完成转身

- **适用**：耳环、耳坠；用真实角度变化表现表面反光，不把光当魔法特效。
- **第 0 帧**：人物的肩和半张脸正在跨越阴影与侧光边界，躯干已开始转向，目光尚未到达终点。
- **唯一事件**：躯干和视线完成一次转身，同时从阴影进入侧光。
- **镜头**：头肩近景，低幅横向伴移并保持人物同侧；终帧让侧脸进入三分位，近侧耳饰处于最清晰角度。
- **物理响应**：躯干先转，头发和衣料稍后跟随，耳饰以更短的延迟响应；高光只因角度改变而变化。
- **商品锁**：锁定耳钩或耳扣、连接环数量、主片外轮廓、点缀相对位置和单耳/双耳可见规则。
- **剪点**：视线抵达画外目标且高光完成变化的第一帧。
- **最小负面**：身份漂移、几何复制、额外首饰、换脸、商品漂浮、文字、logo、水印。

## N. 项链动作

### N1｜跨过门洞链坠追随

- **适用**：Y 形项链、长链、具有明确纵向末端的项链。
- **第 0 帧**：人物已经跨过门洞，前脚落地而后脚仍在门内，躯干先进入光区，完整纵向链路可见。
- **唯一事件**：人物完成这一步；躯干先跨越，衣料随后，最低链坠最后完成延迟回摆。
- **镜头**：中近景沿人物行进方向作一次对角伴移，保持门洞轴线和完整纵向轮廓，终点为偏心侧身构图。
- **物理响应**：衣料随步伐拉伸后回落；链体上段响应较小，末端延迟最明显且自然衰减。
- **商品锁**：锁定链条层数、交汇连接件、纵向部件顺序、末端形状和整体长度比例。
- **剪点**：最低链坠完成第一次回摆、尚未发生第二次摆动时。
- **最小负面**：身份漂移、几何复制、额外首饰、换脸、商品漂浮、文字、logo、水印。

## W. 手腕动作

### W1｜完成动作后露出手腕

- **适用**：手镯、手链；用自然任务揭示佩戴位置。
- **第 0 帧**：手正在松开扶手、离开墙面或在一步之后推回袖口，手掌仍与真实物体保持部分接触。
- **唯一事件**：手完成释放或整理动作，手腕因任务结束自然露出；禁止为展示而单独翻转手腕。
- **镜头**：腰部以上或手臂中近景，沿手的真实路径做一次对角跟移，保持肘、腕、手指在同一空间，终点落在放松手腕。
- **物理响应**：手指依次离开接触面，袖口因前臂运动后退并轻微回落，饰品只随手腕的真实位移响应。
- **商品锁**：锁定开口或闭合结构、中央视觉点、左右点缀数量、端点和佩戴朝向。
- **剪点**：手掌刚离开物体、袖口清开且手腕不再旋转的瞬间。
- **最小负面**：身份漂移、几何复制、额外首饰、换脸、商品漂浮、文字、logo、水印。

## P. 产品证明

### P1｜环境运动证明产品

- **适用**：所有被真实表面支撑的纯产品镜头。
- **第 0 帧**：产品已完整落在石面或织物上；叶影、水面反射、经过的织物阴影或近景前景已开始进入画面。
- **唯一事件**：一个环境变化沿明确方向越过产品，产品本体始终被支撑且不滚动、不悬浮。
- **镜头**：微距或近景，只做一次果断对角移动或低位横移，移动方向与主钩子保持一致；终点对准最能证明身份的结构特征。
- **物理响应**：只有真实光影或前景产生视差；产品的数量、位置、朝向和几何保持不变。
- **商品锁**：锁定总数量、完整外轮廓、连接点、主细节、左右或上下顺序。
- **剪点**：环境运动刚越过身份特征且完整轮廓仍可读时。
- **最小负面**：身份漂移、几何复制、额外首饰、换脸、商品漂浮、文字、logo、水印。

## D. 情绪落点

### D1｜运动落点形成新构图

- **适用**：人物和场景共同收尾的耳饰、项链或手腕镜头。
- **第 0 帧**：人物已在横穿画面、离开前景或接近建筑边界，终点留白尚未形成。
- **唯一事件**：人物完成运动并到达偏心终点；动作因任务完成而结束，不是为了摆姿势突然停下。
- **镜头**：中景或环境人像，和人物保持一个稳定方向，不交叉轴线；终帧把人物置于右三分位或左三分位，并留下单一干净区域供后期选择性加字。
- **物理响应**：脚步先结束，衣摆、发尾和可见首饰按质量依次衰减；建筑透视和光向全程一致。
- **商品锁**：锁定佩戴侧、商品数量、主轮廓、连接结构和与服装的相对位置。
- **剪点**：人物到达新构图而次级运动仍保留极少余量的第一帧。
- **最小负面**：身份漂移、几何复制、额外首饰、换脸、商品漂浮、文字、logo、水印。

## Blender / AE 升级门槛

Blender 和 AE 默认暂停，不进入每日流水线。只有同时满足以下五项，才允许提出一次受控配对测试：

1. 同一重要动作使用首帧和提示词连续失败三次；
2. 失败原因明确属于摄影机路径、人物走位或焦点交接；
3. 使用低成本灰模或 2.5D 控制片即可表达；
4. 与无控制视频版本使用同一首帧和同一目标做配对测试；
5. 一轮对照未显示清晰提升时立即停止，不继续堆叠控制资产。

网上教程、旧 Blender 工程或 AE 动作没有 MythRealms/Maverenne 自身成对证据时，不视为已验证优势。

## 生成后 QA

- [ ] 前 0.5 秒已经出现可感知运动，不从完成姿势起步。
- [ ] 主动作有可见起因、推进过程和一个新状态。
- [ ] 终帧构图不同于首帧，并提供可剪切的干净落点。
- [ ] 人物、商品、接触面、阴影和场景处于同一物理空间。
- [ ] 商品数量、结构、连接点、佩戴位置和比例没有漂移。
- [ ] 主钩子与回应镜头具有可匹配的方向、遮挡清除或光线变化节点。
- [ ] 无未核验材质、价格、库存、履约、低敏、耐久、疗愈、幸运或精神功效承诺。
- [ ] 无身份漂移、几何复制、额外首饰、换脸、漂浮商品、文字、logo 或水印。

失败时一次只调整一个变量，顺序为：开场状态 → 动作幅度 → 镜头关系 → 参考输入 → 场景。不得靠叠加形容词掩盖根因。
